# Технические отличия от оригинального InnerCore

> Рабочий адрес: **https://sleep.kuban-forum.ru** (домен второго уровня под этот проект пока не заводился — используется поддомен на kuban-forum.ru).

---

## 1) Pro для всех

Для всех пользователей по умолчанию включён режим **Pro**, сервис работает абсолютно бесплатно. Логика trial/ограничений отключена:

- `services/billing_service.py` → `has_full_access()` всегда возвращает `True`
- `refresh_entitlements()` принудительно выставляет `user.sub_type = "pro"` для каждого пользователя

Промпты «перейти на Pro» не должны появляться, т.к. `billing/status` возвращает `sub_type: "pro"`.

## 2) Авторизация через email (вместо соцсетей)

- Убрана авторизация через **Telegram, Google, Яндекс ID, VK ID** (может быть добавлена позже).
- Убраны кнопки соцсетей на фронтенде (`AuthModal`), удалён Google GSI-скрипт из `index.html`.
- Добавлена **классическая авторизация через email**: при регистрации на почту присылается код, который нужно ввести на сайте.
- Код вводить необязательно — режим подтверждения можно отключить (см. п.4).
- Отправка писем настроена через **SMTP Яндекс** (`smtp.yandex.ru:465`, SSL).

## 3) Убраны блоки про мобильное приложение и Telegram-бот

- Убраны блоки со ссылками на **мобильное приложение Android** — оно требует пересборки под новый сервер (в нём жёстко зашит адрес сайта).
- Убраны блоки со ссылками на **Telegram-бот**.
- ⚠️ Сама поддержка голосовой диктовки **уже готова на сервере**:
  - в мобильном приложении (Flutter, кнопка 🎤) — запись `.m4a` → `POST /api/v1/audio/transcriptions`
  - в Telegram-боте — голосовые сообщения OGG → WAV → `speech_recognition`
  - в веб-фронтенде голосовой ввод сейчас не используется

## 4) Админ-панель

- Список пользователей с поиском, пагинацией (10/25/50), статусом (активен/заблокирован).
- **Удаление пользователей** — каскадное удаление всех данных (сны, анализы, символы, подписки, memory). Исправлен `IntegrityError` на `UserMemoryDoc` (добавлен `cascade="all, delete-orphan"`).
- **Блокировка/разблокировка** пользователей.
- **Выдача нового пароля** (если юзер забыл свой) — `POST /admin/users/{id}/reset-password`.
- **Отключение авторизации по email** — toggle в админке. Когда коды выключены (`email_auth_enabled=false`):
  - код не высылается на почту;
  - вводить его не нужно;
  - регистрация и вход проходят сразу (без шага подтверждения).
  - Публичный эндпоинт `GET /api/v1/auth/email-mode` сообщает клиенту текущий режим.

## 6) RAG-хранилище: pgvector + HNSW

Главное в сервисе — хранение и анализ снов.

Повышена эффективность использования RAG-хранилища через расширение **PostgreSQL pgvector + HNSW** (Hierarchical Navigable Small World), размерность `vector(768)`.

**Как это работает:**
1. При анализе нового сна HNSW ищет **топ-40** самых похожих фрагментов прошлых снов по cosine distance (`rag_service.py`).
2. Результаты **пере-ранжируются гибридным скором**: embedding + символьное пересечение + архетипы + новизна.
3. Топ-6 чанков впрыскиваются в промпт LLM как **«SEMANTIC MEMORY CONTEXT»**.

**Хранение эмбеддингов:**
- `dream_chunks.embedding_vec` (`vector(768)`, HNSW-индекс `vector_cosine_ops`) — для ANN-поиска в RAG.
- `dream_chunks.embedding_text` (JSON) — для карты снов (попарные cosine в Python).
- `dreams.embedding_text` (JSON) — семантический поиск по всем снам юзера.
- Модель: `gemini-embedding-001`, 768 размерность.

## Дополнения

### LLM-модели и фолбэк-цепочки

| Задача | Модель | Фолбэк |
|--------|--------|--------|
| Анализ и чат | `gemini-3.5-flash-lite` | **Mistral AI** (при сбое) |
| Транскрипция голоса | `gemini-3.6-flash` → `3.5-flash` → `3.5-flash-lite` | локальный **faster-whisper** (offline) |
| Эмбеддинги | `gemini-embedding-001` | — |

Контекст чата увеличен до ~100k токенов (400k символов).

### Семантическая карта снов

- **Рёбра двух типов:**
  - `co_dream` — символы, встречавшиеся в одном сне (вес = число общих снов);
  - `embedding` — семантическое сходство символов (cosine ≥ 0.65).
- **Слияние синонимов** — greedy clustering по cosine ≥ 0.80 (например, «озеро» и «озеро с островами»).
- **Проекция** — UMAP (fallback PCA) → 2D.
- **Кластеризация** — DBSCAN + метки архетипов Юнга.

## Деплой-нюансы

- **Prod**: веб, API, Celery, PostgreSQL 17 + pgvector, Redis, Caddy reverse proxy (TLS).
- **NumPy на проде собран из исходников**: QEMU (виртуальный) CPU не поддерживает X86_V2-оптимизации бинарных wheels NumPy 2.x, поэтому используется `numpy==2.0.2`, собранный с `-march=x86-64`.
- Фронтенд собирается с `VITE_API_BASE_URL=https://sleep.kuban-forum.ru` (не дефолтом с dev).
